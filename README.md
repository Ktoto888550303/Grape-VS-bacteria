# Grape-VS-bacteria
В этой игре предстоит выживать за виноград, упавший на пол, чтобы сработало правило 5 секунд. Как играть? Все очен просто! Прокачивайте свои навыки, развивайте виноград и может быть вы сможете снова попасть на тарелку, или может вы бросите вызов судьбе? Играйте за разные классы и собирайте опыт.
